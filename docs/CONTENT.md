# Content provenance

- Every email, name, company, address, invoice, image and OCR result is **synthetic**, generated by `app/Console/Support/CorpusBuilder.php` with a fixed seed. Domains use `.test`/`example` conventions. No real people, customers or companies are represented; similarity to real ones is coincidental.
- Vendor reference list (`config/sorthouse.php`) is invented.
- All metrics in the UI and docs come from `eval:run` over this corpus; see `docs/EVALUATION.md`. No metric is hand-written, and none is claimed for real inboxes or real models.
- Prices in `config/sorthouse.php` are placeholder estimates in a versioned table, labelled "estimated".
- Model identifiers: only `ANTHROPIC_MODEL` has a default (`claude-sonnet-5-5`); OpenAI and Gemini models must be configured by the operator after checking current documentation.
